# dsh-unity-mcp 0.0.7

这次改版针对引擎操作工具。实测连接的 CoderGamester 服务器提供 34 个工具，并非九十多个；插件将变换、场景、材质和播放状态合并为四个领域入口，保留其他上游操作，共 22 个引擎入口。本地工程管理、安装和连接配置继续独立。

## 调用迁移

- move/rotate/scale/set_transform 改用 `unity_transform`，以 `set`、`translate`、`rotate`、`scale` 选择动作。
- 场景 info/create/load/save/unload/delete 改用 `unity_scene`。
- 材质 info/create/modify/assign 改用 `unity_material`。
- 播放状态与控制改用 `unity_play`，动作是 `status`、`play`、`pause`、`stop`、`step`。

被合并的原始名称不再向 Agent 暴露；其他上游名称保留，但增加参数检查。脚本需迁移到新入口。模型可从参数说明查询适用动作与条件必填，不需要给每个动作补齐无关字段。

## 行为修正

对象目标要求明确且唯一；重设父级不能缺省为场景根，也不允许触发上游“清零位置、旋转和缩放”的分支。适配层会检查字段类型、枚举、数值范围、非有限数值及不受支持的材质路径。场景另存路径必须显式配合 `saveAs: true`，避免把当前活动场景写到一个被误当成选择器的路径。

对象读取默认深度为 0、不展开组件属性；控制台默认 20 条、不带堆栈。需要验证变换或组件值时，应显式请求组件属性。工具描述说明场景 Single 模式、删除不保存、共享材质保存、播放 pause 切换、组件部分更新及批处理不保证原子的限制。适配层不编造上游未返回的对象 ID 或实际变换值。

懒加载和立即加载都使用相同适配层。保留逐 Agent 隔离、断连清理及同 schema 重连时的执行器更新；立即加载不重复注册本地工具。MCP 原始输出和内容投影继续传递。

## 验证

- 自动回归覆盖动作映射、参数失败前拦截、输出投影、执行上下文、逐 Agent 隔离、晚发现、断连和同 schema 重连，以及真实 Cordis ToolRuntime 的懒加载与立即加载。
- 独立团结工程真实完成场景查询、播放状态查询、创建临时对象、设置变换、相对移动、显式读取组件属性并核对数值、删除临时对象。错误目标返回后仍可再次查询场景；四类危险参数在适配层拒绝。没有切换现有 DSH 工程连接。
- 同一批上游定义的引擎 schema 从 25,878 降至 20,931 UTF-8 字节，减少约 19.1%。这是加载后 schema 字节比较，不是模型 token 计数；初始仍只暴露加载入口。

本次没有实机执行场景删除、覆盖材质或切换 Play Mode，也未修复上游 C# 实现。未知材质属性、无效 tag、部分组件更新等仍需写后回读。依赖审计仍有 18 项通告（3 moderate、15 high），未强制升级宿主依赖。
