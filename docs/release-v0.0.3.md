# v0.0.3

新增按 Agent 懒加载的 `unity_open_project`，支持 Windows Unity / Tuanjie 工程。

- 从工程读取精确版本，在标准 Hub 目录发现匹配编辑器，也支持显式 editorPath；不自动升级工程。
- 检测已打开工程、工程锁和同进程重复请求；通过独立参数启动编辑器，不经过 shell。
- 打开工程不保存 MCP 连接配置，不代表编辑器加载完成或 MCP 就绪。启动可能导入资源并执行工程内编辑器脚本，只应打开可信工程。
- 旧连接路径失效时保留本地配置和打开工具，避免整个插件无法激活。

验证：13 项自动测试通过；本机插件调用正确返回当前团结工程 already_open，没有重复启动。新进程启动分支使用注入式模拟测试验证，未额外启动或关闭用户编辑器。当前 profile 原测试工程路径已不存在，尚未切换 MCP 连接到其他工程。

依赖安全通告沿用前版记录，未执行破坏 DSH 兼容性的强制升级。
