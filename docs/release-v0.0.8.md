# dsh-unity-mcp 0.0.8

修复 MCP 异步发现工具后，未调用 `unity_load_tools` 的 Agent 提前看到原始工具的问题。

旧实现只在 Agent 创建和 pre-step 时更新工具遮罩。MCP 在初始化后完成连接或重新发现工具时，新注册的原始工具会暂时暴露。现在监听 `tools/change` 并同步更新每个 Agent 的遮罩；已加载的 Agent 同时获得更新后的适配工具，无需等待下一轮。

同步过程包含重入保护，Agent 销毁时先撤出同步集合，避免清理触发重新注册。`lazyTools: false` 的立即加载选项保留。

真实 Cordis ToolRuntime 回归先在旧实现上复现原始场景工具泄漏，修复后通过。测试覆盖未加载与已加载 Agent、异步注册、移除、同名重新注册、新 Agent 创建、非合并原名工具和独立 Agent 销毁。全部 28 项测试、构建和打包检查通过。本次仅调整工具可见性，没有执行引擎写操作。
